# PM Output — 로그인 페이지에 '비밀번호 찾기' 링크 추가
> 생성일: 2026-05-15

## 요구사항 분석
로그인 폼 하단에 '비밀번호 찾기' 링크를 추가한다.
클릭 시 비밀번호 재설정 페이지(`/forgot-password`)로 이동해야 한다.
추가 기능(재설정 이메일 발송, 토큰 처리 등)은 이 태스크의 스코프 밖이다.

## 태스크 목록
- [ ] 로그인 폼 하단에 '비밀번호 찾기' 텍스트 링크 추가
- [ ] 링크 클릭 시 `/forgot-password` 경로로 이동 처리
- [ ] 기존 로그인 폼 레이아웃이 깨지지 않는지 확인

## 리스크
- `/forgot-password` 라우트/페이지가 아직 없을 경우 404 발생 → 링크 추가 전 라우트 존재 여부 확인 필요
- 링크 스타일이 디자인 시스템과 맞지 않을 경우 → Design 단계에서 확인

## Dev/QA에 전달할 핵심 지침
- 로그인 폼 컴포넌트(또는 페이지 파일)에만 변경 가한다
- 링크 텍스트: '비밀번호 찾기' (또는 '비밀번호를 잊으셨나요?' — Design 확정)
- href: `/forgot-password`
- 기존 로그인 기능(이메일/비밀번호 입력, 제출)은 건드리지 않는다
- `/forgot-password` 라우트 없으면 링크만 추가하고 해당 페이지는 별도 태스크로 분리
