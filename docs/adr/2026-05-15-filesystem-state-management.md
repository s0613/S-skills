# ADR: 파일시스템 기반 상태 관리

**Status:** Accepted  
**Date:** 2026-05-15

## Context
테스트 사이클 번호, 통과율, sj-company 진행 단계 등 세션 간 지속되어야 하는 상태를 어디에 저장할지 결정해야 했다.

## Decision
DB, KV 스토어, 외부 서비스 없이 프로젝트 디렉토리 내 파일시스템(`docs/test-scenarios/.state/`, `docs/sj-company/.state/`)에 텍스트 파일로 저장한다.

## Consequences
- **장점**: 외부 의존성 제로 — 설치 즉시 동작
- **장점**: git에 커밋 가능 — 팀 공유, 히스토리 추적 가능
- **장점**: 사람이 직접 읽고 수정 가능
- **단점**: 동시성 제어 없음 (단일 사용자 환경 가정)
- **단점**: 파일 손상 시 상태 복구 수동 필요
