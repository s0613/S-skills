# ADR: 마크다운 기반 스킬 정의

**Status:** Accepted  
**Date:** 2026-05-15

## Context
Claude Code 스킬을 어떻게 정의할지 선택해야 했다. 코드(JS/TS)로 구현할 수도 있고, 마크다운 지시사항으로 구현할 수도 있다.

## Decision
각 스킬을 `SKILL.md` 단일 마크다운 파일로 정의한다. 코드 없이 자연어 지시사항만으로 스킬의 전체 동작을 기술한다.

## Consequences
- **장점**: 설치 후 즉시 사용, 코드 빌드 불필요, Claude가 직접 해석하므로 유연한 적응 가능
- **장점**: 기여하기 쉬움 — 코드 지식 없이 마크다운만 편집하면 됨
- **단점**: 스킬 동작이 Claude 모델 버전에 종속될 수 있음
- **단점**: 복잡한 로직(파싱, 계산)은 Bash 블록으로 보완해야 함
