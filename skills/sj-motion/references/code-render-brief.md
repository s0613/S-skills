# 코드 렌더 경로 — 브리프 뼈대

코드 렌더는 글자를 **폰트로 그린다.** 생성 모델처럼 한글을 "추측해서 그리지" 않으므로 Text Fidelity 문제가
구조적으로 사라진다. 숫자·차트·UI·로고처럼 틀리면 안 되는 화면은 이 경로가 기본이다.

## 도구 고르기 (실행 위치로 갈린다)

| 실행 위치 | 도구 | 비고 |
|-----------|------|------|
| claude.ai (Team·Enterprise) | **Claude Motion** (베타, 2026-10) — 채팅에서 `/motion` 또는 Output→Motion | 코드 기반 애니메이션 → MP4. 실사 푸티지·인물 없음. 관리자가 코드 실행·Artifacts·Motion 템플릿을 켜야 함. Free·Pro·Max 미포함 |
| Claude Code (HTML 선호) | **HyperFrames** (`heygen-com/hyperframes`, Apache-2.0) | `npx skills add heygen-com/hyperframes` → `/hyperframes` 계열 스킬이 HTML/GSAP 구성 → 로컬 렌더 |
| Claude Code (React·데이터 반복) | **Remotion** (`remotion-dev/skills`) | `npx skills add remotion-dev/skills`. 데이터 주입·템플릿 재사용에 강함. 회사 규모에 따라 유료 라이선스 |

플랜·설치 여부는 **확인하고 고른다**(`ls ~/.claude/skills ~/.agents/skills`). 아무것도 없으면 설치 명령을 보여 주고
설치는 사람 승인 후. 이 스킬이 렌더를 대신 돌리지는 않는다 — 브리프를 넘긴다.

## 브리프 뼈대

주니어 디자이너에게 주는 브리프처럼 쓴다. 이야기와 카피는 이 스킬이 정하고, 애니메이션 구현은 도구가 맡는다.

```
목적: {누가 · 어디서 보고 · 무엇을 기억해야 하나 — 한 문장}
길이: {N}초 · 화면비: {9:16 | 1:1 | 16:9} (코드 경로는 화면비를 여기서 정한다)
시청 환경: {피드 무음 재생 → 모든 핵심은 화면 텍스트로 | 발표 화면 | …}
소재 제한: 첨부한 자료에 있는 사실·수치만. 새 주장·효능 금지.
톤: {Brand Voice 2~3개} · 팔레트: {hex 또는 색 이름+역할} · 서체: {이름 또는 성격}

장면:
1. {t0–t1s} {역할: Hook} — 화면 문구 "…" / 등장 방식 / 강조할 숫자
2. …
N. {마지막 0.7~1.0s} End Card — "{CTA 원문}" 정지, 새 요소 없음

모션 원칙: 의미에 맞는 모션만(빠름=반복 슬라이드, 하나로=수렴, 매일=리듬). 이징은 ease-out 기본.
금지: 자료에 없는 로고·UI·인물, 3D 회전.
```

## 쓰는 요령
- **숫자 하나를 주인공으로.** before→after 수치 대비가 가장 강한 장면이 된다.
- 무음 피드 전제면 voice_over 없이 텍스트만으로 이해되게 쓴다.
- 수정은 통째 재생성 대신 **한 곳만 지시**한다("2번 장면 0.5초 느리게") — 코드라 나머지는 그대로 남는다.
- 실사 질감·캐릭터 연기가 필요한 장면만 생성 모델로 따로 만들고, 그 클립 위에 텍스트를 코드로 얹는다(하이브리드).
