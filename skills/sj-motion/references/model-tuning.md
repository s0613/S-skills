# 생성 모델별 튜닝 (생성 경로 전용)

뼈대(prompt-template.md)는 공통이다. 대상 모델이 정해지면 **표현만** 아래처럼 조정한다.
출처는 2026년 공개 가이드들이고 모델은 자주 바뀐다 — 사용자가 버전을 말하면 그 버전 기준으로 확인하고, 확인 못 했으면 공통 뼈대를 그대로 쓴다.

| 모델 | 잘 듣는 형태 | 조정 |
|------|--------------|------|
| Seedance 2.x | 인과로 이어지는 긴 서술 + 레퍼런스 태그(이미지·영상·오디오 입력) | 현재 뼈대 그대로. 레퍼런스는 `@image1` 식 태그로 지칭하고 각 Shot이 앞 Shot의 결과에서 출발하게 쓴다 |
| Kling 3.x | Subject + Action + Scene + Camera/Lighting/Atmosphere 4요소 | Shot마다 이 순서로 한 문단. 장문 Visual Style은 짧게 줄이고 Shot 안에 반복 핵심만 |
| Veo 3.x | 자연스러운 촬영 언어 + JSON 비슷한 구조 필드 | `style:` `camera:` `audio:` 같은 필드 라벨을 붙여 블록화. 대사·사운드 지시가 실제로 반영되므로 sound 블록을 살린다 |
| Runway Gen-4.x | 짧고 정확한 문장 | 6,000자 기본값 적용 안 함. Shot별 30~60단어로 나눠 클립 단위 생성 |

## 공통으로 효과가 큰 것
- **Shot당 주체 하나.** 복잡한 구성은 모델이 풀지 못한다.
- 표면·동작·카메라·조명 대비를 구체적으로 쓴다.
- 같은 프롬프트도 모델마다 강점이 다르다 — 중요한 광고면 2개 모델로 돌려 비교하도록 권한다.
- **한글 카피가 많으면 생성 경로를 고집하지 않는다.** 배경 플레이트는 텍스트 없이 생성하고(`no text in frame`) 카피는 코드 경로로 얹는다.
