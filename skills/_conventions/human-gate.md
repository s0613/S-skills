# 사람 게이트 (Human Gate)

> **build the loop, stay the engineer.** 루프는 일을 대신하지만 검증·이해·승인은 사람 몫이다.

## 규칙

**PR 머지와 프로덕션 배포 승인은 항상 사람이 한다.**
어떤 스킬·루프·자동화·서브에이전트도 이 두 가지를 자동 실행하지 않는다.

## 적용 지점

| 상황 | 요구 동작 |
|------|-----------|
| sj-ship 호출 (push/PR 생성) | 디스패치 전 현재 브랜치 확인 + AskUserQuestion으로 사용자 승인. 취소 불가 작업이므로 생략 금지 |
| 루프 프롬프트 작성 (sj-loop) | 가드레일 섹션에 "git push·PR 머지·프로덕션 배포 금지" 문구 필수. 문구 없는 루프는 저장 금지 — 저장 전 `grep -q "사람 게이트" {루프파일}` 기계 검증 |
| 루프 실행 중 머지 준비 완료 | 머지하지 않는다. `docs/sj-company/triage-inbox.md`에 기록하고 멈춘다 |
| 클라우드 스케줄·cron 자동 실행 | 위와 동일 — 무인 실행일수록 게이트가 더 중요하다 |

## 경계

- **커밋·피처 브랜치 push는 게이트 대상이 아니다** — 사용자가 명시적으로 요청했고 사전 확인을 거쳤다면 수행 가능.
- 게이트 대상은 정확히 둘: **PR 머지**, **프로덕션 배포**.
