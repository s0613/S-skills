# 비대화형 실행 (Non-Interactive)

## 규칙

**사용자가 없는 실행에서는 질문 대신 가정을 쓰되, 가정한 사실을 반드시 기록한다. 그리고 사람 게이트는 가정으로 대체하지 않는다.**

## 감지

```bash
[ -n "$SJ_NONINTERACTIVE" ] && echo "MODE=noninteractive" || echo "MODE=interactive"
```

환경변수가 없어도 **호출자가 "사용자 없음"을 명시했으면 비대화형이다** — 서브에이전트로 디스패치됐거나,
행동 테스트 픽스처에서 실행 중이거나, 크론·루프가 돌린 경우가 여기 해당한다.

## 비대화형에서의 행동

1. **`AskUserQuestion`을 호출하지 않는다.** 호출하면 응답이 오지 않아 실행이 멈춘다.
2. **각 강제 질문에 합리적인 가정을 채우고, 산출물의 `## 가정` 절에 기록한다:**
   ```markdown
   ## 가정
   - {질문 요지}: {가정한 답} (사용자 미답변)
   ```
3. **기록 없이 진행하지 않는다.** 가정을 세우고 안 적으면 그건 은폐다 ([honest-report.md](honest-report.md)).
4. **되돌릴 수 있는 선택은 좁은 쪽을 기본값으로 한다** — 스코프는 MVP, 범위는 최소, 추상화는 없음.
   틀렸을 때 넓히는 비용이 좁히는 비용보다 싸다 ([minimal-code.md](minimal-code.md)).
5. **사람 게이트는 가정으로 대체할 수 없다** — 아래 참조.

## 출력 캡처 — 화면 전용 산출도 단언 가능하게

일부 스킬은 산출이 **화면 텍스트뿐**이다(sj-company 라우팅 결정, sj-secretary 상태 보고).
파일이 안 남으니 행동 테스트가 무엇도 단언할 수 없고, 그래서 이 스킬들은 회귀망 밖에 있었다.

**`SJ_OUTPUT_FILE`이 설정돼 있으면 사용자에게 보이는 보고를 그 경로에도 그대로 쓴다.**

```bash
[ -n "$SJ_OUTPUT_FILE" ] && echo "CAPTURE=$SJ_OUTPUT_FILE" || echo "CAPTURE=off"
```

- 화면 출력은 평소대로 한다 — 캡처는 **추가**지 대체가 아니다.
- 설정 안 돼 있으면 아무것도 하지 않는다. 평상시 동작은 바뀌지 않는다.
- 읽기 전용 스킬도 이 파일만은 쓴다 — 테스트 하네스가 준 경로이지 대상 프로젝트가 아니다.

이것이 없으면 "행동 테스트가 없는 스킬"과 "행동 테스트를 만들 수 없는 스킬"이 구별되지 않는다.

## 사람 게이트는 예외 (가장 중요)

비대화형이 "전부 예라고 가정"이 되면 이 컨벤션은 안전장치가 아니라 우회로가 된다.

**다음은 "예"로 가정하지 않는다** ([human-gate.md](human-gate.md)):

- PR 머지, 프로덕션 배포
- 되돌리기 어렵거나 파괴적인 작업 (파일·브랜치·데이터 삭제, 히스토리 재작성)
- 외부로 나가는 것 (메일 발송, 게시, 외부 API 쓰기)
- 다른 저장소·다른 사람의 작업 공간을 바꾸는 것

이 지점에 도달하면 **멈추지 말고 그 항목만 남긴 채 나머지를 끝낸다**:

```markdown
보류: 사람 승인 필요 — {무엇을, 왜 자동으로 못 하는지}
```

전체를 중단하는 것도, 승인을 가정하는 것도 틀렸다. 할 수 있는 일을 끝내고 게이트를 남긴다.

## 이유

행동 테스트를 만들려 할 때마다 이 문제에 걸렸다. 스킬은 강제 질문으로 요구사항을 좁히도록
설계됐는데, 서브에이전트에는 답할 사람이 없어 실행이 멈춘다. 그래서 세 번에 걸쳐 매번
"가정으로 채우고 명시하라"를 프롬프트로 흉내 냈다 — 매번 문구가 달랐고, 사람 게이트를
어떻게 다룰지는 아예 규정하지 않았다.

자동으로 돌지 않는 절차는 회귀 테스트를 가질 수 없다. 그리고 회귀 테스트가 없으면
`self-harness.md`의 "회귀가 녹색일 때만 채택"은 아무것도 보증하지 못한다.

## 시행 지점

- 강제 질문을 가진 역할 스킬 — 질문 전에 모드를 감지하고, 비대화형이면 가정으로 대체
- `docs/superpowers/fixtures/behavior/` — 행동 테스트 3케이스가 이 계약에 의존한다
- 루프·크론이 돌리는 실행 — 사람이 없는 것이 기본값이다
