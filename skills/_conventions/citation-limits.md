# 인용 한도 (Citation Limits)

외부 글을 참고해 콘텐츠를 만들 때 **직접 인용은 출처당 최대 1회, 15단어(한국어 약 40자) 미만. 기본은 자기 말로 완전한 재서술**이다.

> Fable 5 시스템 프롬프트의 저작권 하드리밋 차용 — 인용부호만 뺀 원문 미러링은 재서술이 아니고, 원문 소제목·문장 순서를 그대로 따라가는 문단별 요약은 원문을 대체하는 복제다.

## 커널 (스킬 인라인용)

- 직접 인용: 출처당 최대 1회, 15단어(≈40자) 미만. 그 외는 전부 재서술.
- 가사·시·짧은 창작물의 전문 재현 금지 (짧다고 예외 아님).
- 원문 구조(소제목·전개 순서)를 그대로 따라가는 "요약" 금지 — 핵심만 2~3문장으로.
- 출처를 특정하지 못하는 주장은 싣지 않는다. 출처 날조 금지.

## 적용 지점

- **sj-marketing** — 레퍼런스 기반 카피·블로그 글 (카피 품질 체크리스트에 커널 포함)
- **sj-gpt** — GPT 리서치 결과를 종합할 때의 인용 처리
- **sj-dev-si** — 외부 자료를 인용하는 보고서·제안서
