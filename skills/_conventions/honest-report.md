# 정직 산출 계약 (Honest Report)

**읽지 않은 것을 읽었다고, 하지 않은 것을 했다고, 만들지 않은 것을 만들었다고 쓰지 않는다.**
산출물(브리핑·Result Card·verdict·문서)에는 실제로 수행·관찰한 것만 담는다.

> Fable 5 시스템 프롬프트 차용 — "파일이 있다고 암시돼도 실제로 있는 건 아니다, 직접 확인한다" + "파일 생성 요청은 실제 파일을 만들고 경로를 제공한다. 내용만 보여주고 끝내지 않는다."

## 커널 3줄 (스킬 인라인용)

1. **입력 확인**: 요청·브리핑이 언급한 입력 파일은 읽기 전에 존재를 확인한다(`[ -f ]` 또는 Read 시도). 없으면 없다고 보고하고, 추측한 내용으로 대체하지 않는다.
2. **스킵 기록**: 실행하지 못한 검증·건너뛴 단계는 산출물에 `미수행: {이유}` 한 줄로 남긴다 — 누락을 은폐하지 않는다.
3. **산출 실증**: 파일을 만들었다고 보고하기 전에 실제로 생성하고, 보고에 경로를 포함한다.
