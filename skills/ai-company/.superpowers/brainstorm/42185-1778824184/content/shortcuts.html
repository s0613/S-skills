단축키 체계 — 어느 방향이 좋으세요?

3-컬럼 레이아웃 기준. 현재: Ctrl+C(종료), Ctrl+L(로그토글), q/ESC(종료) 뿐입니다.

── 이동 ──
↑ / ↓ 채팅 스크롤
PgUp/Dn 채팅 페이지 이동
── 입력 ──
↑ / ↓ 명령 히스토리 (빈 입력창)
Ctrl+K 입력 초기화
Ctrl+C 실행 중 태스크 취소
── 앱 ──
Tab 채팅↔로그 스크롤 포커스
? 단축키 도움말 오버레이
q / :q 종료

A. 스크롤 중심

↑/↓가 채팅 스크롤에 집중. 명령 히스토리는 입력창이 비어있을 때만 ↑/↓로 접근. Tab으로 채팅/로그 패널 포커스 전환.

── 입력 ──
↑ / ↓ 명령 히스토리 (항상)
Ctrl+K 입력 초기화
Ctrl+C 태스크 취소 (2번→종료)
── 뷰 ──
Ctrl+↑/↓ 채팅 스크롤
Ctrl+L 로그 패널 확대/축소
── 앱 ──
? 단축키 도움말
q / :q 종료

B. 히스토리 중심

↑/↓는 항상 명령 히스토리 전용. 채팅 스크롤은 Ctrl+↑/↓. Ctrl+C 첫 번째는 태스크 취소, 두 번째는 앱 종료.

── 입력 ──
↑ / ↓ 명령 히스토리 (빈 입력창)
Ctrl+K 입력 초기화
── 패널 스크롤 ──
[ / ] 채팅 스크롤 ↑ / ↓
{ / } 로그 스크롤 ↑ / ↓
── 앱 ──
Ctrl+C 태스크 취소
? 도움말
q / :q 종료

C. 브래킷 스크롤

채팅은 [ ], 로그는 { }로 스크롤. ↑/↓는 명령 히스토리 전용. vim 스타일에 익숙하다면 충돌 없이 직관적.
