A. Tab 탭 전환

Tab 키로 Dept/Log/Help 탭 사이 전환. 현재 탭이 상단에 강조. 단축키 힌트도 Help 탭에 통합.

장점

  • 직관적 탭 UX
  • Help 탭으로 단축키 통합

  • 한 번에 하나만 표시

B. 분할 항상 표시

Dept+Budget 고정 상단, 로그 최근 3줄 하단에 항상 표시. Ctrl+L은 로그 전체화면 팝업으로.

장점

  • 전환 없이 모두 보임
  • 로그 실시간 흐름 확인

  • 각 섹션 공간이 좁아짐
